# 作業點收系統 — 學生數位聯絡簿與成績登記端

支援作業自主檢核、小考成績登記、7天聯絡簿與生活心得隨筆的學生數位聯絡簿端，目標全面取代實體聯絡簿。

## 核心功能特色
1. **班級代碼與座號即時綁定**：支援網址參數 `?code=[班級代碼]&seat=[座號]` 直達。
2. **今日作業自主檢核**：自主勾選完成作業，同步掌握老師收件狀態（已繳交、待訂正、未繳交）。
3. **今日小考與測驗成績填寫**：支援各科成績登記、分數統計（今日平均分、測驗筆數）、訂正狀況標記與錯題檢討心得。
4. **過去 7 天聯絡簿與導師公告**：過去一週聯絡簿橫向時間軸切換。
5. **生活心得隨筆 / 心情札記**：五款心情狀態選擇與心得筆記，取代實體聯絡簿心情欄。
6. **一鍵複製 LINE 回報格式**：一鍵產生今日作業與成績摘要文字，便利回傳給家長。
7. **雙向儲存與離線 PWA**：本機 LocalStorage 高速秒開 + Firebase Firestore 即時雲端備份。
